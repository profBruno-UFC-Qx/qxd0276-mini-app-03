# 📱 Mini-App 3: Mini-Quiz

## 🎯 Objetivo
Aplicar **gerenciamento de estado** e **navegação simples** entre telas em Jetpack Compose.

## 📋 Funcionalidades
- Tela inicial com botão **Iniciar Quiz**.
- Exibir ao menos **5 perguntas de múltipla escolha** (uma por tela).
- O usuário seleciona a resposta e avança para a próxima.
- Ao final, exibir a **pontuação final**.
- Botão para **reiniciar o quiz**.

## ✅ Requisitos Técnicos
- Uso de **estado** para armazenar pergunta atual e pontuação.
- Navegação implementada com condicionais (`if`) ou `when` (sem Navigation Component).
- Interface criada apenas com Jetpack Compose.
